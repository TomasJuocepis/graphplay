Files you can import

Edge list — one edge per line: A B, A,B, A -- B (undirected) or A -> B (directed). An optional third column (or trailing text) becomes the edge name. Quote names with spaces. A line reading directed makes plain edges directed. A line with one name is an isolated node.

DOT (.dot, .gv) — graph / digraph with label= attributes on edges.

GraphML — edgedefault, per-edge directed, and label/weight data keys.

JSON — { "directed": false, "nodes": [...], "edges": [{"source","target","label"}] }.

When a subgraph has directed edges, its strongly connected components are listed in a third menu (a component is a source when nothing leads into it from other components, a sink when nothing leads out, and middle otherwise). Node colors match the component. "Show condensation" swaps the view for the condensation graph, where each node is one component and each edge counts the underlying edges between two components.

Word list — a plain file with one word per line (a dictionary such as the public-domain ENABLE list) becomes a graph where words are linked when they differ by one letter, like the Short Scrabble Words preset. You choose the maximum word length.

Edit dataset opens the current graph as text you can change and re-apply; Export downloads it as an edge list, JSON, or DOT file (all three re-import here).

The city set is a curated list of about 300 cities with populations over one million; distances are great-circle, in km.
